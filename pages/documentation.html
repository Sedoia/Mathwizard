Technical and Product Documentation

Authoritative reference for onboarding, architecture, data model, and release operations across the Math Wizard platform.

Version 1.0.4 Last Updated: March 2026 Audience: Team and Faculty

Quick Start

  • Run the project locally with static hosting and Firebase configuration.
  • Use dedicated test roles for player and admin verification.
  • Validate login, profile, item management, and delete-account flows.

Architecture Summary

Frontend pages are static HTML with Tailwind utilities and shared scripts. Authentication and persistence are handled by Firebase Auth and Firestore.

Data Collections

  • users: account profile, role, and privacy preferences.
  • players: progression, inventory, and learning statistics.
  • shop_items: admin-managed store inventory.

Design and UX Standards

Pages follow a unified visual language, responsive breakpoints, touch-safe controls, and clear state feedback for all critical actions.
